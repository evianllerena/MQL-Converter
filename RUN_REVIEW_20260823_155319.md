# Review of DIAGNOSTICS_20260823_155319

## Outcome

- Application: MQL ONE v5.0.0, real pipeline, frozen EXE.
- Compiler: auto-discovered OANDA TMS MT5 `MetaEditor64.exe`.
- Input: 30 MQ4 indicators.
- Delivered: 6.
- AI queue: 24.
- Deterministic improvement versus the previous run: 1 delivered to 6.
- Fifteen of the 24 queued files ended with only one or two compiler errors.

## Why the queue stopped

The configuration had `agent_enabled=true`, but `claude_path` was blank. More
importantly, v5.0 real mode had no AI-queue consumer. The random AI behavior in
the source existed only in demo mode. Therefore the queue was a terminal label,
not a working repair stage.

## Remaining compiler-error concentration

The captured logs contained 217 error occurrences across 24 distinct messages.
The largest groups were:

- 59 wrong-parameter-count errors, including eight 7-vs-9 argument cases.
- 23 enum-conversion errors.
- 20 expression-expected cascades.
- 17 missing `CurTime` references.
- 14 missing-return-path errors.
- Repeated variable-scope defects involving `i`, `whichBar`, `TimeFrameStr`,
  `k`, and `dVolty`.
- Invalid legacy object/property and plot-value usage.

## Additional defects found

1. Diagnostics represented a blank configured MetaEditor path as `.` and
   incorrectly reported that directory as the compiler. Runtime discovery was
   nevertheless correct, as proven by `events.log` and produced EX5 files.
2. Several converted `OnInit` bodies closed before a global `return(0);`.
3. Several `void OnDeinit` bodies still returned a value.
4. The old repair rule depended on MetaEditor naming `OnDeinit` in error text;
   the compiler generally reported only “void function returns a value.”
5. The raw log collection may represent the initial compile rather than every
   internal repair pass; the ledger contains the authoritative final count.

## v5.1 response

- Real Codex CLI queue worker in isolated per-file folders.
- Independent MetaEditor recompilation after every agent edit.
- Candidate promotion only when errors decrease; direct delivery only at zero.
- Three attempts maximum, followed by `MANUAL_SEMANTIC_REPAIR_REQUIRED`.
- Deterministic lifecycle repairs added before agent escalation.
- Auto-discovered compiler path is now recorded truthfully in diagnostics.

Compile verification remains separate from runtime equivalence. Originals must
remain preserved, and compiled indicators still require buffer/plot comparison
against their MT4 references.
